## Context and Orientation

Before this work, the repository mostly contained product/design docs (`docs/`) and an MVP decomposition file. Epic 0 requires foundational project scaffolding. The implemented baseline introduces:

- Root workspace manifest (`Cargo.toml`) to define members and workspace-level metadata.
- Core crate (`crates/core`) that compiles and contains unit tests.
- CI workflow (`.github/workflows/ci.yml`) that installs stable Rust, restores/builds cache, and runs format/lint/test commands.
- Starter runtime configuration template (`config.example.toml`) containing placeholder but realistic fields for future epics.
- Updated `README.md` with concise onboarding/build steps.

## Plan of Work

Create the workspace manifest first so all subsequent commands have a root project context. Add the core crate with minimal code and tests to satisfy compile/test acceptance requirements. Add `rustfmt.toml` and CI workflow to formalize formatting/linting expectations. Add `config.example.toml` for configuration skeleton requirements. Update `README.md` to describe purpose and exact local checks. Finally, update `MVP_DECOMPOSITION.md` with an Epic 0 checkpoint statement and run all Rust checks locally.

## Concrete Steps

From repository root `/workspace/openoman`, run:

    cargo fmt --all -- --check
    cargo clippy --all-targets --all-features -- -D warnings
    cargo test --all-targets --all-features

Expected behavior: all commands exit successfully. `cargo test` should report two passing tests in `crates/core/src/lib.rs`.

## Validation and Acceptance

Acceptance is met when a contributor can run the three commands above locally and see success, and when GitHub Actions would run the same checks on PR and `main` push. The decomposition file should explicitly show Epic 0 completion via a checkpoint note under Epic 0.

## Idempotence and Recovery

All created files are declarative and can be regenerated by reapplying the same content. If a command fails, rerun after fixing the reported issue. No destructive migrations or irreversible data changes are involved.

## Interfaces and Dependencies

The workspace uses stable Rust toolchain and standard library only; no third-party Rust dependencies are needed for Epic 0. CI relies on `dtolnay/rust-toolchain@stable` for compiler setup and `Swatinem/rust-cache@v2` for dependency and target caching.
